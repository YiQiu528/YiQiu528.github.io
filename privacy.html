XxtCalendar 隐私政策

最后更新：2026年11月15日

1. 数据访问

应用通过用户授权的 Google Calendar API 访问日历事件，用于学习通作业与课程日程的同步、 创建和更新。

2. 数据存储

应用在 Windows 本地存储同步状态。 Google OAuth 令牌使用 Windows DPAPI 进行本地加密保护。

3. 数据传输

学习任务信息按用户设置同步至其 Google Calendar。 应用不将 Google 日历数据出售给第三方， 不使用这些数据投放广告。

4. 撤销授权

用户可在 Google 账号安全设置中 撤销对本应用的访问权限。

5. 联系方式

请通过应用的开发者联系邮箱咨询隐私问题。
